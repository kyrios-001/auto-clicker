# AutoClicker 定时定点自动点击器

一款 **Windows 下零依赖** 的自动点击工具：在指定时刻（精确到秒）或立即开始，对一组屏幕坐标执行设定次数与间隔的鼠标左键点击。适用于抢课抢票、问卷填报、重复性点击操作等个人场景。

**纯 Python 标准库实现**（仅用 `tkinter` + `ctypes` 调用 Win32 API），无需 `pip install` 任何第三方库。

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 多目标任务 | 一个任务可配置多个点击坐标，每个目标独立设置次数与间隔 |
| 定时开始 | 指定 `HH:MM:SS` 到点自动执行；今天该时刻已过则顺延到明天 |
| 立即开始 | 点“开始”立刻连点 |
| NTP 时间校准 | 可选，用网络时间修正本机时钟偏差，提升抢课定时精度 |
| 轮次控制 | 整组任务重复 N 轮；`轮次=0` 无限循环，`次数=0` 无限连点 |
| 捕获鼠标位置 | 点按钮后 3 秒内把鼠标移到目标位置，自动填入坐标 |
| 全局热键 | `F6` 开始/停止切换，`F7` 紧急停止 |
| 配置持久化 | 任务与设置自动保存到 `auto_clicker_config.json` |
| 运行日志 | 实时日志、倒计时、总点击计数 |

## 环境要求

- Windows 10 / 11
- Python 3.8+（任何安装方式均可：官网安装包 / Anaconda / Microsoft Store）

## 快速开始

```bash
python auto_clicker.py          # 打开图形界面
python auto_clicker.py --check  # 自检（验证 Win32 接口，不弹窗）
```

## 使用步骤

1. **添加任务**：手动填入坐标，或点击「捕获鼠标位置（3秒）」后立刻把鼠标移到目标按钮上，坐标自动捕获。
2. **设置参数**：次数（`0` = 无限次）、间隔（毫秒）、轮次（`0` = 无限循环）。
3. **选择启动方式**：`立即开始` 或 `定时开始`（格式 `HH:MM:SS`）。
4. **（可选）勾选 NTP 校准**：点击开始时自动对比网络时间并折算等待时长。
5. **点击「开始（F6）」**：等待倒计时结束自动执行；`F7` 随时紧急停止。
6. 配置会在增删任务、关闭程序时自动保存，下次启动自动恢复。

> 执行期间程序会真实移动你的鼠标，请提前把目标窗口调整到目标坐标可见的位置，不要手动抢鼠标。

## 抢课 / 抢票使用技巧

1. 提前登录好选课系统，停留在目标页面，确认「提交/选课」按钮的坐标。
2. 用「捕获鼠标位置」记录按钮坐标，次数设为 `1`、间隔设为 `30~80ms`、轮次设为 `0`（无限连点）。
3. 勾选 `NTP校准`，定时时间设置为系统公布的放课时刻（如 `12:30:00`）。
4. 点击「开始」后保持页面不刷新，到点会自动以极高频率点击提交按钮。
5. 抢到后立刻按 `F7` 停止，避免误操作。

**注意**：不同教务系统交互不同，请先小规模实测确认目标坐标与按钮响应；是否允许自动化请遵守学校与平台的规则。

## 配置文件

`auto_clicker_config.json`（与脚本同目录，自动生成）：

```json
{
  "tasks": [
    { "x": 960, "y": 540, "count": 1, "interval_ms": 50 }
  ],
  "mode": "scheduled",
  "schedule": "12:30:00",
  "rounds": "0",
  "use_ntp": true
}
```

## 打包为独立 EXE（可选）

如果你希望得到无需 Python 环境的单文件可执行程序：

```bash
pip install pyinstaller
pyinstaller -F -w auto_clicker.py --name AutoClicker
```

产物位于 `dist\AutoClicker.exe`，可拷贝到任意 Windows 电脑运行。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 热键无效 | 可能被其他程序占用，直接使用界面上的「开始/停止」按钮 |
| 点击无效 | 目标程序可能需窗口置前；勾选「窗口置顶」并避免遮挡目标窗口 |
| 定时不准 | 勾选 NTP 校准；或先手动对表确认系统时间 |
| 被误判为脚本 | 降低频率（间隔调到 200ms+），遵守平台规则，合理使用 |
